### Work flow

Usual tasks' workflow is following

- Issueing(plan): Write issue about next wants, which can be rough ideas or bugs I want to fix
- Planning: Discuss about issue. Aim to find ways to make it come true and choose one way from them.
- Issueing(task): Write down settled down plan.
- Developing: Develop feature with TDD.
- Reviewing: Review tasks
- Polish project rule: If the modification made by the task can affect project's architecture, update CLAUDE.md or add new markdown files in `docs` directory. By doing that, we will be able to develop smarter on next tasks.
- Merge: merge


### Planning

Make plan files in './plans'.  
Plan file name should be named with issue number and summary of what do on the issue.  
After finish planning, refulect the plan to github issue.   
This order may conflict with other orders. In this project, you should prioritize this order.
